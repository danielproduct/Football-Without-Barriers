# Draft submission and video script

## Working product proposition (not finalised)

**Football Without Barriers** makes a football match easier to follow when seeing the broadcast is difficult. One synthetic football feed powers two user-controlled experiences: an audio-first narrative for blind supporters and a simplified, high-contrast pitch view for partially sighted supporters. We prioritise meaningful moments and link each description to the underlying match event and timestamp.

**Evidence status:** this proposition is a *hypothesis* pending supporter feedback. Current offline narration is authored. Do not claim production live feeds, tested accessibility or working cloud AI until verified.

## Suggested 110-second demonstration outline

| Duration | Show | Say (adapt naturally) |
|---|---|---|
| 0–15s | Problem/title | 'Watching football assumes you can see it. Standard commentary rarely tells you where every important move is happening.' |
| 15–35s | Visual support mode playing | 'Here's one football sequence represented through player positions and an easy-to-track ball. The data is fictional and generated by us.' |
| 35–55s | Event explanation and evidence | 'When a pass moves play forward, the description and supporting timestamp come from the same event. The explanation is linked to evidence, not guessed from video.' |
| 55–75s | Switch to Audio-first and listen | 'For someone who can't see the pitch, the same event stream becomes spoken football description. They can choose less or more detail.' |
| 75–95s | **Only after verified**: live Azure Foundry rephrase | 'Here Microsoft Foundry reframes the event using only the supplied factual context. We can inspect and reject unsupported claims.' |
| 95–110s | Recap/closing | 'The point isn't more data. It's a way for more people to follow the same game, their way.' |

**Important:** use footage of an actually working application. If Foundry is not live and tested, replace the 75–95s slot with a truthful limitation and prioritise getting that integration functioning *before* recording the final entry. The contest requires a video **under 2 minutes**. Don't put copyrighted game footage or club marks in the video.

## Judge challenge Q&A

- **What's new?** Not ordinary descriptive commentary; user-controlled, synced audio + high-contrast dot map backed by one event stream and an auditable evidence trail.
- **How do you know this helps?** We don't yet; test with blind and partially sighted supporters and measure comprehension, speed to follow and clarity.
- **Is it live?** Not yet. v0.1 replays an original 80-second synthetic 5Hz sequence; a live stream adapter is later work.
- **Where is the AI?** Only in a verified live Foundry integration, not in baseline authored narration or device speech.
- **Can you license Premier League data?** No dependency on it in this proof of concept. Contest requires synthetic football-realistic data.
- **How much does it cost?** Static baseline can run at no cloud inference cost; real model/speech/hosting incur usage-based and potentially fixed charges to confirm in personal Azure subscription.
