## Suggested order (prioritised to reduce failure risk)

1. Get the static POC into the personal repository and verify Pages; capture visual/UX feedback.
2. Set up one real Microsoft Foundry model (personal Azure, budget alert) and validate a minimal explanation call.
3. Demonstrate a distinct two-stage explanation workflow or verifiable agentic collaboration only if it materially strengthens the entry. Do not fake multiple agents.
4. Configure speech, measure response latency, add explicit failure fallback, run truthfulness tests.
5. Publish the complete judge-accessible build, then record the video and submit.
